# Humans may assist the table but never the robot seat

One arm cannot reach the whole table, so the physical gate uses human assistance within a fixed boundary. Humans may deal, play the three other seats, give event signals that carry only timing, and place tiles the robot must take (its wall draws and claimed discards) in the fixed shared zone. The robot seat's cameras alone decide tile identity, including public discards and melds, and the robot alone chooses its actions and handles its own hand. Any corrective touch to the robot's tiles or arm fails the trial.

We rejected free assistance because it would make the reliability numbers depend on the operator. We rejected full autonomy (the robot handling the wall and other seats) because it adds table logistics without testing the strategy-to-manipulation interface this project claims. We rejected human-announced tile identities because they would bypass the perception-to-strategy link that gate four exists to test.
